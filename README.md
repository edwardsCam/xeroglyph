
# Xeroglyph

My collection of algorithmically generated artwork. All written by me, no AI.

[xeroglyph.com](https://xeroglyph.com)

## Help
In any piece:
* Hit `Esc` or `i` to bring up an info panel.
* Hit `o` to open an options panel where you can tweak parameters or restart the drawing.

## Run it locally
* `yarn install`
* `yarn start`
